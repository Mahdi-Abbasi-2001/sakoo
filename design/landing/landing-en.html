  1. Step 1

    Reads

    It opens the zip or clones the repository and looks for manifests. Each decision keeps the file it came from.

    docker-compose.yml · service web
  2. Step 2

    Plans

    It chooses apps, databases and disks. It asks only when the files do not answer, for example a worker with no port.

    worker has no port → worker
  3. Step 3

    Waits for you

    It stops at an approval that shows the total per hour and per month, VAT included. Nothing exists on your account yet.

    4,583 toman/hour · 3,300,000/month
  4. Step 4

    Creates and checks

    It creates one resource at a time, then requests the URL. If a build fails it diagnoses the cause. A fix that costs money waits for you.

    http_200 · blog-web.liara.run

03 · Input

What it reads

It recognises these files and the platform each one implies.

  • docker-compose.yml

    Each service becomes an app or a database. Postgres, Redis and others are matched by image.

  • Dockerfile

    App platform docker.

  • package.json

    node, next, react, vue or angular, chosen from the dependencies.

  • requirements.txt · pyproject.toml

    django, flask or python, chosen from the dependencies.

  • composer.json

    laravel or php.

  • go.mod

    go.

  • manage.py

    django.

04 · Readiness

What it checks

Before it asks you to approve, it reports these findings with the file and line. It never prints a secret value.

  • Warning

    env_file_present
    A .env file with values is in the project. It is not uploaded.

  • Warning

    hardcoded_secret
    A secret is written in the code: an AWS key, a private key, an API key or an assigned secret. Reported by location only.

  • Warning

    debug_enabled
    Debug mode is on.

  • Info

    allowed_hosts_wildcard
    Allowed hosts accepts any host.

  • Warning

    sqlite_data_loss
    SQLite data on the app's disk is lost on redeploy unless you use a Liara disk or database.

  • Warning

    binds_localhost
    The app listens on localhost, so Liara cannot reach it.

  • Info

    writes_local_files
    The app writes local files. A disk would keep them.

  • Warning

    foreign_service_dependency
    It calls a service that may be unreachable from Liara's network: Telegram, OpenAI, Anthropic, Google AI or Discord.

05 · Rules

What it never does

These are how the agent behaves, not promises about the service.

  1. 01

    It creates nothing before you press Apply. The approval shows the total per hour and per month, VAT included.

  2. 02

    It does not apply a fix that costs money without asking. The price difference is shown first. Free fixes, such as refreshing database credentials, are applied and listed.

  3. 03

    It shows secret names, never values. A finding points to a file and line, not to the value.

  4. 04

    It works in your own Liara account, in the team you pick when you connect. [placeholder: token scope and storage]

  5. 05

    A dry run sends nothing. It lists the exact requests a real run would make: method, path and summary.
